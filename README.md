
# Mini Alura - Alura LATAM Clone  

## Description  
This project is a **miniature clone of the Alura LATAM website**, created to practice **web layout, responsive design, and CSS structuring**. The goal was to replicate the **visual style and structure** of Alura in a simplified version, reinforcing skills in **HTML and CSS**.

- HTML  
- CSS  

## What I Learned  
This project helped me improve my **CSS styling techniques**, including **flexbox, grid, and typography**, to achieve a visually appealing and structured layout. It also enhanced my ability to **replicate UI components** from an existing website.  

## Ongoing Development  
I plan to refine the design and experiment with **CSS animations and accessibility improvements** to enhance the user experience.
