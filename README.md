**Mini Alura** is a front-end project inspired by the visual style and learning platform of **Alura Latam**. It was created to practice semantic HTML, responsive layout, and introductory DOM scripting using JavaScript.

## 🌐 Live Preview

- 🔗 **Live Website**: [https://proyectaminialura.netlify.app](https://proyectaminialura.netlify.app)  
- 📁 **GitHub Repository**: [https://github.com/Aleji0309/proyectaMiniAlura](https://github.com/Aleji0309/proyectaMiniAlura)

## 🛠️ Technologies Used

- **HTML5** – Page structure and semantic tags  
- **CSS3** – Layout styling, colors, and responsiveness  
- **JavaScript (ES6+)** – Basic interactivity and DOM logic  
- **Netlify** – Deployment and hosting

## 📋 Project Description

This project features a landing page with sections commonly found on an educational platform:

- Hero header and navigation  
- Category blocks or courses  
- A footer with branding and links  
- Light JavaScript interaction

The goal of this site was to practice layout, color usage, spacing, and accessible content structure in a real-use scenario.

## 📌 Key Features

- Static multi-section layout  
- Responsive design using Flexbox and media queries  
- Clear visual hierarchy and brand consistency  
- Lightweight JavaScript for minor interactions  
- Inspired by the design aesthetics of Alura Latam

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Aleji0309/proyectaMiniAlura.git
````

2. Navigate to the project folder:

```bash
cd proyectaMiniAlura
```

3. Open the `index.html` file in your browser.

> This project is static — no build or install steps are needed.
